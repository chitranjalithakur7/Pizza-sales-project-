# Pizza-sales-project-

🍕 Pizza Sales Analysis - SQL Project
📌 About the Project

This project is based on Pizza Sales Analysis using SQL. It focuses on analyzing customer orders, popular pizza types, and overall sales performance. The goal is to gain useful insights from the data to support better business decisions.

🗂️ Dataset Information

The project uses four main tables:

Orders – Contains order ID, date, and time
Order Details – Includes quantity and pizza IDs for each order
Pizzas – Stores pizza size and price
Pizza Types – Contains pizza names, categories, and ingredients
🎯 Objectives
Analyze total number of orders
Identify best-selling pizzas
Understand customer ordering patterns
Calculate total revenue
Find peak order times
⚙️ Tools & Technologies
SQL (MySQL / PostgreSQL)
Database Management System
Canva (for presentation)
📊 Key Analysis Performed
Data retrieval using SELECT queries
Joins to combine multiple tables
Aggregation functions (COUNT, SUM, AVG)
Grouping and sorting data
Sales and revenue analysis
📈 Insights
Identified most popular pizza categories
Determined peak hours for orders
Analyzed revenue contribution of each pizza
Found customer preferences
✅ Conclusion

This project demonstrates how SQL can be used to analyze real-world business data. It helps in understanding sales trends and improving decision-making for a pizza business.
